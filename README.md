## About

Regions Unexplored adds biomes that feel like they could have shipped with the game. Silver birch groves, blackwood forests, prairies, bayous, alpine highlands and pumpkin fields — all built with vanilla's restraint, so they blend into the world rather than shouting over it.

---

## Features

- Sixty-plus biomes designed to sit naturally alongside vanilla terrain
- New wood types with complete block families and leaf variants
- Cave biomes and underground terrain variation
- New flowers, plants and decorative natural blocks
- Careful colour palettes that avoid clashing with vanilla biomes

## Installation

1. **Download** the JAR matching your Minecraft version from the table above.
2. **Install a mod loader** — Forge, Fabric or NeoForge for your exact game version.
3. **Place the `.jar`** into your `.minecraft/mods/` folder (create it if it is missing).
4. **Launch** Minecraft using the modded profile.
5. Verify **Regions Unexplored** appears in the in-game mods list.

> **Tip:** if the game crashes on startup, you almost certainly mixed a Legacy JAR with a Modern
> Minecraft version, or are missing a required dependency. Check `latest.log` first.

## FAQ

**Q: Does it feel out of place?**
A: It is designed not to — the art direction deliberately matches vanilla.

**Q: Compatible with Terralith?**
A: Yes, and the combination is popular; both inject rather than replace.

**Q: New world needed?**
A: Recommended, but exploring outward into fresh chunks works too.

**Q: Is it safe to add to an existing world?**
A: Yes in most cases — back the save up first, as you should with any mod addition.

**Q: Can I use it in a public modpack?**
A: Yes. Both builds are modpack-ready and require no additional setup.
